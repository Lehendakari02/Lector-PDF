# Datos de idioma para reconocer texto (OCR)

`spa.traineddata` es el modelo de español de Tesseract, versión "fast" 4.1.0,
tal como lo publica el proyecto Tesseract (https://github.com/tesseract-ocr/tessdata_fast).
Licencia: Apache License 2.0.

SHA-256: `6f2e04d02774a18f01bed44b1111f2cd7f3ba7ac9dc4373cd3f898a40ea6b464`

El motor de reconocimiento (Tesseract) ya viene dentro de PyMuPDF; este archivo
es lo único que hay que añadir para que funcione en español.
